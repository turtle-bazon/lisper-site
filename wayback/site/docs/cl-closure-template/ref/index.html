Парсер¶

Function closure-template:parse-template (obj)¶
Парсит либо строку, либо файл (для его указания необходимо использовать pathname) с шаблонами Closure Templates и возвращает внутреннее представление.

Компиляция¶

Generic Function closure-template:compile-template (backend obj)¶

Компилирует OBJ с помощью BACKEND. В качестве BACKEND можно передавать keyword-ы, например: :common-lisp-backend или :javascript-backend.

В качестве OBJ можно передавать:

  • string

  • pathname

  • list, содержащий объекты, которые можно передавать в closure-template:compile-template

JavaScript backend¶

Function closure-template:compile-js-templates (templates)¶
Вызывает closure-template:compile-template с аргументами :javascript-backend и TEMPLATES.

Common Lisp backend¶

Function closure-template:compile-cl-templates (templates)¶
Вызывает closure-template:compile-template с аргументами :common-lisp-backend и TEMPLATES.

Function closure-template:ttable-register-template (ttable)¶
Регистрирует в TTABLE функцию TEMPLATE с именем NAME.

Function closure-template:ttable-find-template (ttable lname)¶
Ищет в TTABLE скомпилированный шаблон с именем LNAME. Если такого нет, то возвращает nil.

Function closure-template:ttable-call-template (ttable name env &optional stream)¶
Ищет в TTABLE шаблон NAME и вызывает его с параметрами ENV. Опциональный параметр stream используется для указания потока вывода. Если вместо stream указан nil, то возвращает строку с результатом работы шаблона.

Function closure-template:ttable-extend-package (ttable package)¶
Для каждого зарегистрированного шаблона в TTABLE создаёт в PACKAGE новую функцию, которая при вызове производит вызов соответствующего шаблона с помощью closure-template:ttable-call-template.

Function closure-template:ensure-ttable-package (name &key prototype)¶
Проверяет существует ли пакет с именем NAME. Если такого пакета нет, то он создаётся, в него добавляется символ *PACKAGE-TTABLE* и этому символу присваивается новый объект closure-tepmlate:ttable. Если указан PROTOTYPE, то он используется при создании closure-template:ttable.

Function closure-template:package-ttable (package)¶
Возвращает объект класса closure-template:ttable, связанный с PACKAGE.

Generic Function closure-template:fetch-keys (map key)¶
Используется для доступа к свойствам MAP по ключу KEY. Объекты, для которых реализован данный метод могу быть использованы в качестве словаря при передаче в шаблоны.

Generic Function closure-template:fetch-property ()¶
Используется для получения списка свой объекта MAP. Объекты, для которых реализован данный метод могу быть использованы в качестве аргумента функции keys при вызове шаблона.
