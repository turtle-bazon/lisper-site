Функции¶

Функция Использование
isFirst($var) Используется только внутри блока foreach. См. подробности в разделе foreach, ifempty, /foreach
isLast($var) Используется только внутри блока foreach. См. подробности в разделе foreach, ifempty, /foreach
index($var) Используется только внутри блока foreach. См. подробности в разделе foreach, ifempty, /foreach
isNonnull(value) Возвращает true если значение определенно и не равно null
length(list) Длина списка
keys(map) Возвращает ключи словаря в виде списка. Какой-либо порядок не гарантируется.
augmentMap(baseMap, additionalMap) Создаёт "расширенный" словарь, содержащий значения как из baseMap, так и из additionalMap. Если какой-либо ключ есть в обоих словарях, то значение берётся из additionalMap.
round(number) Округляет до целого.
round(number, numDigitsAfterDecimalPoint) numDigitsAfterDecimalPoint обозначает количество знаков после запятой
floor(number) Возвращает наибольшее целое, меньшее или равное аргументу
ceiling(number) Возвращает наименьшее целое, большее или равное аргументу
min(number, number) Возвращает минимальное из двух чисел
max(number, number) Возвращает максимальное из двух чисел
randomInt(range) Возвращает случайное целое в диапазоне [0, range - 1] (range должно быть положительным целым)
strContains(str, subStr) Проверяет является ли subStr частью str

Директивы print¶

Функция Использование
noAutoescape Данная директива отключает автоматическое экранирование специальных символов HTML, которое производится для защиты от XSS.
escapeHtml Включает автоматическое экранирование специальных символов HTML для защиты от XSS. Эта директива используется в шаблонах, для которых отключено автоматическое экранирование.
escapeUri Используется для экранирования строки, которая может быть использована в качестве параметра URI
