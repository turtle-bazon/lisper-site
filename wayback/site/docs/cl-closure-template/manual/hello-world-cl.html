Hello World¶

Выполните следующие действия, чтобы создать простой шаблон Hello World и использовать его в JavaScript:

  1. Создайте рабочий каталог, например:

    mkdir ~/helloworld_js/

  2. Создайте в этом каталоге файл simple.tmpl и скопируйте туда следующую строку:

    {namespace examples.simple}

    Эта строка объявляет пространство имён для всех шаблонов, которые будут размещены в данном файле.

  3. Скопируйте следующий простой шаблон и поместите его в после объявления пространства имён:

    {template helloWorld}
       Hello world!
    {/template}

    Этот шаблон просто создаёт строку "Hello world!".

  4. Запустите вашу реализацию Common Lisp (cl-closure-template разрабатывается в основном с использование SBCL, но должна работать и с другими реализациями) и выполните следующий код (не забудьте поправить путь к файлу):

    (ql:quickload "closure-template")

    (closure-template:compile-cl-templates #P"/home/youname/helloworld_js/simple.tmpl")

    ВАЖНО: путь к шаблону должен быть указан как pathname.

  5. В результате будет создан package с именем '#:examples.simple, а в нём создана функция #'examples.simple:hello-world. Выполните эту функцию:

    (examples.simple:hello-world)

    В результате вы должны получить строку:

    "Hello world!"

    Вот и всё! Вы только что создали с помощью cl-closure-template самый простой шаблон и использовали его в Common Lisp. В следующем разделе мы рассмотрим ещё пару примеров.

Hello Name and Hello Names¶

  1. Добавьте в simple.tmpl второй шаблон, называемый helloName. Данный шаблон требует параметр name, а также имеет опциональный параметр greetingWord. Этот шаблон также демонстрирует использование команды if-else. Вы можете расположить этот шаблон до или после helloName, но в любом случае после определения пространства имён.

    {template helloName}
       {if not $greetingWord}
           Hello {$name}!
           {else}
           {$greetingWord} {$name}!
       {/if}
    {/template}

  2. Добавьте в simple.tmpl третий шаблон helloNames, который демонстрирует использование цикла foreach с командой ifempty. Он также демонстрирует как вызывать другие шаблоны и вставлять их вывод с помощью команды call. Примечание: атрибут data="all" в команде call указывает передать в вызываемый шаблон все параметры, которые были переданы вызывающему шаблону.

    {template helloNames}
       // Greet the person.
       {call helloName data="all" /}<br>
       // Greet the additional people.
       {foreach $additionalName in $additionalNames}
           {call helloName}
               {param name: $additionalName /}
           {/call}
           {if not isLast($additionalName)}
               <br>  // break after every line except the last
           {/if}
       {ifempty}
           No additional people to greet.
       {/foreach}
    {/template}

  3. Перекомилируйте файл с шаблонами:

    (closure-template:compile-cl-templates #P"/home/youname/helloworld_js/simple.tmpl")

  4. Выполните в REPL следующий код:

    (progn
      (write-line (examples.simple:hello-world))
      (write-line "-----------------")
      (write-line (examples.simple:hello-name '(:name "Ana")))
      (write-line "-----------------")
      (write-line (examples.simple:hello-name '(:name "Ana"
                                                :additional-names ("Bob" "Cid" "Dee")    )    )    )
      (values)    )

  5. Вы должны увидеть следующее сообщение:

    Hello world!
    -----------------
    Hello Ana!
    -----------------
    Hello Ana!<br> Hello Bob! <br> Hello Cid! <br> Hello Dee!
