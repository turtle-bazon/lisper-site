Система шаблонов cl-closure-template¶

cl-closure-template вдохновлена Google Closure Templates и реализует язык шаблонов Closure Templates. Документация по Google Closure Templates в части описания языка шаблонов в значительной степени может использоваться и как документация по cl-closure-template. Существующие различия описаны на странице Отличия от оригинальной реализации.

cl-closure-template реализует систему шаблонов для серверной и клиентской стороны, которая позволяет динамически создавать повторно используемые HTML и UI компоненты. Язык шаблонов имеет простой, естественный для программистов синтаксис. В отличие от традиционных систем, в которых каждый шаблон описывает целую страницу, вы можете использовать cl-closure-template для создания небольших компонентов и комбинировать их для создания пользовательского интерфейса.

Преимущества использования cl-closure-template¶

  • cl-closure-template обеспечивает простой способ создания фрагментов разметки и отделения логики приложения от представления.

  • Язык шаблонов не зависит от используемого языка программирования и реализован для JavaScript и Common Lisp. Вы можете написать один шаблон и использовать его как на клиенте, так и на сервере.

  • Вы можете чётко видеть структуру генерируемого HTML глядя на структуру кода шаблонов.

  • Язык шаблонов ориентирован на программистов. Шаблоны это просто функции, которые могу вызывать друг друга. Синтаксис включает в себя конструкции, знакомые любому программисту. В один исходный файл можно поместить несколько шаблонов.

  • cl-closure-template может быть использована вместе с любой библиотекой или фреймворком.

  • Вы можете указать свои шаблоны непосредственно при описании ASDF-систем.
