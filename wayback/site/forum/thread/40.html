Автор: archimag - 10.08.2009 14:44
> как получить директорию относительно которой запускается конечный бинарник

Ну, если речь о винде, то там же в API есть функция GetCurrentDirectory (если я правильно помню, давно это было). Я совершенно не в курсе, насколько SBCL поддерживает виндовый API, но, в любом случае, его можно научить её вызывать с помощью CFFI или, если не хочется тянуть лишнюю зависимость, с помощью встроенного FFI.

> Нельзя ли для этого бинарника сделать свой собственный sbclrc?

Бинарник - это не более, чем сохраннённый образ, использование которого сокращает время загрузки, но динамичествие свойства CL никуда не деваются. Поэтому, всегда можно вызвать (load #P"/path/fo/file") для загрузки произвольного файла, в котором, например, можно хранить какие-то настройки.
