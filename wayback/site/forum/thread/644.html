LinkFly - 01.10.2011 17:22
[#] Ответ на комментарий от LinkFly 01.10.2011 17:22
>Между делом - глобальные лексические переменные в CL есть...

Нет.

Синтаксис оператора let :

let ({var | (var [init-form])}*) declaration* form* => result*

где

results---the values returned by the forms.


То есть: (let ((my-var 200)) (f)) => 101 - вернул результат последней вызванной формы (that is, the body of a let is an implicit progn ->тело let - неявный progn). Первой и последней вызывается определённая в топ-левеле f, не имеющая никакого отношения к локальной my-var.


Об этом, кстати, сообщает компилятор в варнинге:

* (let ((my-var 200)) (f))
; in: LET ((MY-VAR 200))
;     (LET ((MY-VAR 200))
;       (F))
;
; caught STYLE-WARNING:
;   The variable MY-VAR is defined but never used.
;
; compilation unit finished
;   caught 1 STYLE-WARNING condition

101
