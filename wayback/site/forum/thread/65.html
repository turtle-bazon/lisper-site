Автор: archimag - 25.09.2009 16:05, Сообщений - 8

Делаю перевод PCL в формате PDF, возникло несколько проблем, которые я пока не знаю как разрешить:

  • Как вставлять в документ гиперссылки (pdf это позволяет)? 
  • Как создать outline (bookmark) для произвольного места внутри страницы? На главы я делаю с помощью pdf:register-page-reference, но это получается только закладка на страницу. Для создания закладок на подразделы надо уметь создавать закладки внутри страницы.
  • Возможно кому-то уже приходилось создавать с помощью cl-typesetting таблицы в "стиле html". Для имеющихся в cl-typesetting таблиц надо точно указывать ширину столбцов и нельзя объединять ячейки.
