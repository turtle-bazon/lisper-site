[#]
asdf-install позволяет производить автоматическую установку только в достаточно простых случаях. В сложных необходимо ставить пакеты руками. Могу посоветовать посмотреть libCL - большому набору пакетов.

> Планирую использовать Emacs для работы с лиспом из-за присутствия REPL
Emacs стоит использовать из-за SLIME, который, в числе прочего, включает в себя и REPL, и это сейчас фактический единственный вменяемый способ разработки, и, вероятно, в ближайшее время появление других инструментов маловероятно, уж больно он хорош :)

> даже по сравнению с моим textmate
Не хотелось бы устраивать холивар, для этого есть LOR :) Emacs+SLIME+SBCL - это и есть полная среда разработки.

> или дистрибутив линукса
В данный момент лучший дистрибутив для работы с Common Lisp - Gentoo, но не сам по себе, а в месте с gentoo-lisp-overlay (доступен чере layman), которые содержит самые свежие пакеты и постоянно обновляется и подавляющее число нужных пакетов можно устанавливать средствами дистрибутива. Кроме того, turlte начал проект по поддержке самых свежих пакетов для систем на базе Debian: https://developer.bazon.ru/projects/debian-lisp/.
