Передача переменных по ссылке
gmihalkov - 01.02.2013 00:25, Сообщений - 6
Я слабо знаю этот язык, так что сильно не бейте.
В C++ была такая возможность:
void f (int *v)
{
v = 5;
}

int a = 1;
f (&a);

После этого a становилось равно 5.
Есть ли в CLisp возможность передать переменную в функцию по ссылке?
Или, к примеру, связать две переменные (так, чтобы изменение содержимого одной изменяло содержимое первой)?

P.S. "CLisp" - конкретная реализация, язык - "Common Lisp" или "CL". )

Только в обсуждении там какая-то ерунда, а между тем, функцию foo можно было написать как-нибудь так:

(defun foo (l)
  (rplaca l (cadr l))
  (rplacd l (cddr l)))

И всё бы прекрасно работало.

У меня в библиотеке есть, понадобилось, когда переносил код с другого языка. Реализуется как обёртка и набор макросов.

[code=common lisp]
>(defun ПринятьПоСсылке (параметр)
      (with-byref-params (параметр)
         (setf параметр 5)))
ПринятьПоСсылке

> (let ((x 4)) (ПринятьПоСсылке (byref x)) x)
5
[/code]
